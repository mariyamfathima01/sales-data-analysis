 Sales Data Analysis Project

 Project Overview

This project analyses retail sales data using Python to identify sales trends, profitable product categories, loss-making products, and the relationship between discounts and profit.

 Tools and Technologies

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

Dataset

Sample Superstore Dataset containing 9,994 records and 13 columns.

 Project Steps

1. Imported Python libraries.
2. Loaded the dataset.
3. Explored the dataset.
4. Checked missing values and duplicate records.
5. Cleaned the dataset by removing duplicate records.
6. Analysed sales and profit by category.
7. Analysed sales and profit by region.
8. Analysed sales and profit by sub-category.
9. Studied the relationship between discounts and profit.
10. Created visualisations and summarised business insights.

 Key Findings

* Technology generated the highest sales and profit among the product categories.
* Phones had the highest sales among sub-categories.
* Copiers generated the highest sub-category profit.
* Tables recorded the largest sub-category loss.
* A 10% discount level had the highest average profit in this dataset.
* Several higher discount levels showed negative average profit.

 Project Outcome

This project helped develop practical skills in data cleaning, exploratory data analysis, data visualisation, and business insight generation using Python.
